# Root-Me Badge Generator

## Features ✨

- **Données Officielles :** Taux de réussite basé sur le nombre de challenges présent par catégories et validés par l'utilisateur.
- **Session Automatique :** Récupération de la session (`spip`) via la librairie python browser-cookie3 (Chrome, Firefox, Edge, etc.).
- **Rendu Visuel Pro :** Génère un badge au format PNG affichant les différentes catégories et informations de l'utilisateur.
